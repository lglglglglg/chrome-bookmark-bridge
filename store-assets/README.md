# 商店截图素材

商店截图请从真实扩展界面截取，避免使用模拟 UI 或虚构的同步结果。建议尺寸为 1280×800 或 640×400，统一浅色主题。

推荐文件名与演示数据：

1. `01-home.png`：主界面；书签栏、其他书签两个位置可见。
2. `02-encrypted-send.png`：输入演示密码后显示“生成并加密”。
3. `03-file-import.png`：导入 `书签桥同步码.bookmarkbridge` 后显示文件名。
4. `04-preview.png`：显示“阅读资料”文件夹、书签数量和智能合并选项。
5. `05-merged.png`：显示新增数量、跳过重复项数量。

演示数据建议使用：

- 文件夹：`阅读资料`、`工作工具`
- 书签：`OpenAI`、`Chrome Extensions`、`MDN Web Docs`
- 不要出现真实 Google 账号、个人网址、密码或完整同步码。
