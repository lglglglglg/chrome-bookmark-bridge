书签桥隐私政策

生效日期：2026-09-19

书签桥（以下简称“本扩展”）尊重你的隐私。本政策说明本扩展如何处理信息。

我们处理什么信息

本扩展只在你主动点击相关按钮时读取当前浏览器配置文件中的书签，用于生成书签快照、预览和合并。书签内容可能包含网址、标题和文件夹名称。

本扩展不会读取或处理 Gmail、Google 账号凭据、密码、浏览历史、网页内容或其他浏览器配置文件的数据。

数据是否上传

不会。本扩展没有远程服务器、分析服务、广告 SDK 或账号系统。书签快照只在本地生成；如果你设置密码，会通过 Web Crypto AES-GCM 加密。同步码由你自行复制、粘贴或保存为文件，本扩展不会接收或上传它。

本扩展不会自动保存或恢复同步码。关闭扩展界面后，接收区会保持空白，避免误操作旧数据。

权限用途

  • bookmarks：读取和创建你明确选择的书签。
  • clipboardWrite：在你点击“复制同步码”时写入剪贴板。
  • sidePanel：仅在你点击“在侧边栏选择文件”时打开扩展自己的侧边栏，用于选择本地同步文件；不会读取网页内容。

本扩展不申请读取剪贴板、网络访问、标签页、历史记录或身份信息权限。

数据保留与删除

本扩展不会在开发者服务器保留任何数据。你可以删除同步文件、清空剪贴板或在 chrome://extensions 中清除本扩展数据。

安全提示

请通过可信渠道传递同步码，不要把同步码和密码一起发送给不可信对象。忘记密码后，开发者无法恢复加密内容。

政策变更与联系方式

如果本扩展未来改变数据处理方式，我们会更新本政策的生效日期和内容。如有问题或建议，请在 GitHub Issues 提交；请勿在 Issue 中粘贴真实书签、同步码或密码。
