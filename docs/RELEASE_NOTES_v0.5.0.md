`书签桥 v0.5.0｜持久撤销、恢复副本与选择性合并`

## 发布说明

- 最近 7 天、最多 20 次合并历史保存在浏览器本机，关闭弹窗后仍可撤销。
- 合并前可下载目标位置恢复副本，并可沿用接收密码加密。
- 差异预览支持逐条排除书签或整个文件夹。
- 识别精确重复、同网址不同标题和同标题不同网址冲突。
- 冲突可以选择保留两份或跳过同网址项目。

所有合并历史仅保存在本机，不包含同步码、密码或完整书签内容。
