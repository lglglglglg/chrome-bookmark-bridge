# 书签桥 v0.4.8

## 发布标题

`书签桥 v0.4.8｜自动化测试与统一打包`

## 发布说明

这一版专注工程质量，没有改变书签桥的使用流程。

- 拆分可独立测试的同步码、加密和书签树核心模块。
- 增加 BM1/BM2、加密、错误密码、损坏输入和序列化自动化测试。
- 增加统一打包脚本，一次生成 Chrome、Edge ZIP 和 SHA-256。
- GitHub Actions 自动执行测试、打包和安装包一致性校验。
- 补充项目主页、浏览器描述和最低 Chrome 版本声明。
