# 书签桥 v0.6.0

## 发布标题

`书签桥 v0.6.0｜大型差异筛选与传输摘要`

## 发布说明

- 大型差异列表支持关键词搜索、状态筛选和每次追加显示 100 条。
- 支持批量选择或排除当前筛选结果。
- 支持导出完整差异报告，不包含同步码或密码。
- 文件导入后显示文件大小、BM 格式、压缩和加密状态。
- 解密后显示来源浏览器、来源文件夹、格式版本和内容数量。
- 比较大型新增书签树时分批让出主线程并显示精确进度。
- 持久撤销会保护被用户移动、改名或修改过的节点。
